如何免費取得 Google Gemini API Key

準備好了嗎？直接前往 Google AI Studio

使用您日常登入的 Google 帳號即可免費申請。

開啟 Google AI Studio
1

前往 Google AI Studio 網站

在瀏覽器中開啟官方連結 aistudio.google.com/app/apikey，並以您的 Google 帳號登入。

若您是第一次登入，系統可能會提示您同意《服務條款 (Terms of Service)》，勾選同意並點擊「Continue」即可。
2

建立 API 金鑰 (Create API key)

進入頁面後，點擊藍色的 「Create API key」 按鈕。

對話框選項說明
  • Create API key in new project：若為第一次申請，選擇此項，系統會自動為您建立一個全新的 Google Cloud 專案。
  • Create API key in existing project：若您已有 GCP 專案，亦可選取現有專案進行綁定。
3

複製金鑰並貼回本系統

畫面會顯示一串以 AIzaSy... 開頭的長字串。點擊 「Copy」 複製該金鑰。

回到系統設定，將金鑰貼入「Gemini API Key」欄位並點選儲存即可！

常見問題與安全防護

Q1: 申請 API Key 需要付費嗎？

不用。Google 提供免費額度 (Free Tier)，預設每分鐘可進行最多 15 次請求 (RPM)，非常足夠日常學術研究探勘使用。

Q2: 我的 API Key 放在這裡安全嗎？

本系統為純前端應用程式，您的 API Key 僅會儲存在您自己的瀏覽器 (LocalStorage) 中，絕對不會上傳或透露給任何第三方伺服器。
